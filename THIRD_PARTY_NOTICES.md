## What's covered

This document acknowledges third-party open-source software that
`ike-platform` (the consumer-facing parent POM, BOM, and workspace
plugin) depends on or transitively makes available to projects that
inherit `ike-parent` or import `ike-bom`. It covers the Java
language and runtime, the BOM-managed dependency families, signing
infrastructure, and runtime libraries consumers pick up indirectly.

For corresponding notices in the rest of the IKE platform see:

- [ike-tooling](https://ike.network/ike-tooling/THIRD_PARTY_NOTICES.html) — Maven build infrastructure, plugin core, signing.
- [ike-docs](https://ike.network/ike-docs/THIRD_PARTY_NOTICES.html) — AsciiDoc rendering chain, fonts, DocBook, frontend assets.
